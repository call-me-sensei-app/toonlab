# Tree species morphology references

This directory is the evidence set for Toonlab's 165-species procedural-tree
roster. It is generated by:

```sh
node scripts/collect-tree-species-references.mjs
```

Each record in `manifest.json` contains:

- the accepted scientific name and pinned Kew Plants of the World Online URL;
- a descriptive secondary source;
- the source page, creator, and license for a whole-plant reference image;
- a local, review-sized copy of that image in `images/`;
- the current Toonlab architecture and structural-trait mapping.

The images are research and QA evidence, not runtime textures or redistributable
Toonlab assets. Their individual license and attribution metadata remain in the
manifest.

Run `npm run verify:tree-species-references` before accepting a mapping change.
That check fails if any roster entry lacks taxonomy evidence, a descriptive
source, or a locally downloaded licensed image.

Taxonomy/reference collection is not morphology approval. A species remains
marked `experimental` in Tree Lab until all five stages and representative
seeds pass front, side, and back visual review against its saved evidence.
