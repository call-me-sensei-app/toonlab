# ToonLab Pro launch world (repository-only)

This authored review scene connects a contemporary anime city avenue, a coastal
park, and an evening food alley. It is launch-film staging first, but the scene
module deliberately exposes stable bounds, a ground-height function, semantic
style labels, and collision intent so the approved assets can later be moved
into the public walkable reference without rebuilding them.

- `/labs/launch-world/?shot=coast` — city-to-coastal-park shot.
- `/labs/launch-world/?shot=alley` — evening food-alley shot.
- `/labs/launch-world/?shot=face` — character material close-up.
